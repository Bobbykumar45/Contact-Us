# Contact Us CRUD Project

This is a Contact Us web application built using HTML, CSS, and Python (Flask).
The project implements full CRUD operations (Create, Read, Update, Delete).

## Features
- Create: Add new contact details using a form
- Read: View all submitted contact messages
- Update: Edit existing contact information
- Delete: Remove contact records

## Technologies Used
- HTML
- CSS
- Python (Flask)

## How to Run This Project

1. Install Python on your system
2. Install Flask:
   pip install flask
3. Run the application:
   python app.py
4. Open browser and go to:
   http://127.0.0.1:5000/

## Note
This project is created for learning and practice purposes.
CRUD operations are handled using Flask backend.
